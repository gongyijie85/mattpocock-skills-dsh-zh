name: research
description: 针对高可信度的 primary sources（一手来源）调查一个问题，并将发现以 Markdown 文件形式记录到仓库中。当用户想要调研某个主题、收集文档或 API 事实，或把阅读的跑腿工作委托给后台 agent 时使用。
---

启动一个 **background agent（后台代理）** 来做调研，这样它在阅读时你可以继续工作。

它的任务：

1. 针对 **primary sources（一手来源）** 调查问题——官方文档、源代码、specs、第一方 API——而不是对它们的二手转述。把每一个论断都追溯回拥有它的来源。
2. 把发现写入单个 Markdown 文件，并引用每个论断的来源。
3. 把它保存到仓库中已有的此类笔记存放处；遵循现有约定；如果没有约定，就放到一个合理的位置并说明放在哪里。
